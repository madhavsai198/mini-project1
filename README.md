A college mini project that predicts student placement outcomes using supervised machine learning classification models. The system analyzes academic grades, technical ratings, aptitude scores, soft skills, internships, and backlogs, presenting results and profile improvement suggestions through an interactive Streamlit dashboard.

---

## 📌 Project Architecture & Workflow

1. **Data Preprocessing & Cleaning** (`src/preprocessing.py`):
   - Categorical encoding (`gender`, `placement_status`).
   - Feature Z-score standardization (`StandardScaler`).
   - Prevention of data leakage using fit/transform separation.

2. **Exploratory Data Analysis (EDA)** (`src/eda.py`):
   - Statistical analysis comparing placed vs. non-placed student cohorts.
   - Summary metric calculations (`data/processed/eda_summary.json`).

3. **Machine Learning Model Comparison** (`src/train.py` & `src/evaluate.py`):
   - Trains and compares **3 classification algorithms**:
     1. **Logistic Regression**
     2. **Decision Tree Classifier**
     3. **Random Forest Classifier**
   - Evaluates models on 200 test validation students using Accuracy, Precision, Recall, F1-Score, ROC-AUC, and Confusion Matrix.
   - Dynamically selects the best-performing model based on test-set F1-Score.

4. **Prediction Engine & Probability Estimation** (`src/predict.py`):
   - Calculates placement prediction ('Placed' / 'Not Placed') and model-estimated placement probability percentage.

5. **Rule-Based Recommendation Engine** (`src/recommendations.py`):
   - Decoupled from the ML model; provides actionable suggestions across Academic, Coding, Aptitude, Soft Skills, and Backlog domains.

6. **Streamlit Web Application** (`app.py`):
   - Interactive dashboard for prediction, EDA visualization, model benchmarks, and improvement planning.

## 🚀 Step-by-Step Execution Guide

### 1. Data Generation & Preprocessing
Generate raw student data and run preprocessing:
```bash
python data/generate_raw_data.py
python src/preprocessing.py
```

### 2. Run Exploratory Data Analysis
```bash
python src/eda.py
```

### 3. Model Training & Selection
Train all 3 classifiers, evaluate on test set, and export artifacts:
```bash
python src/train.py
```

### 4. Launch Streamlit Web Dashboard
Run the Streamlit application:
```bash
python -m streamlit run app.py
```

## ⚠️ Important Disclaimer

The placement probabilities generated by this system are **model-estimated probabilities** calculated by the trained machine learning algorithms based on historical training data patterns. They do **not** guarantee employment or campus placement outcomes.
